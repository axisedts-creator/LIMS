Title: CR-C10-<nnn>: ObservationDto.hours_since_planting must be a 2-decimal number, not an integer
From chunk: C10            To owner: C0-0C
Type: api
Blocking? yes — C10 06-IMPLEMENTATION-PLAN T-07 (M2 culture detail; observations[].hours_since_planting) and every later task that returns ObservationDto (M15/M16 etc.)
Problem (what you cannot do today, with the user story / acceptance criterion it serves):
  spec/chunks/C10-microbiology/02-TRD.md:108 (§4.1) defines `hours_since_planting` on observations = (observed_at − planted_at) in hours, 2 decimals;
  05-SCHEMA.md:801 stores it as numeric(8,2). 02-TRD.md:308 (§5.6) lists `hours_since_planting?` in ObservationDto without a type.
  contracts/openapi/micro.yaml:6202-6205 declares it `type: integer` (min 0, max 100000), and ObservationDto is closed, so a value such as 24.17 h
  cannot be returned as specified; any conformant response must drop the decimals that 02-TRD §4.1 requires. Serves AC-02.1 / AC-02.3 (culture detail).
Proposed change (exact): contracts/openapi/micro.yaml, components.schemas.ObservationDto.properties.hours_since_planting:
  -          type: integer
  +          type: number
             minimum: 0
             maximum: 100000
  (value is a JSON number rounded to 2 decimals, e.g. 24.17; no multipleOf, to avoid float-precision false negatives in ajv).
  Update the example values (micro.yaml lines 279, 511, 893, 2381: `hours_since_planting: 2`) only if desired; integer examples remain valid numbers.
Backward compatible? yes for consumers reading it as a number (integer ⊂ number). Generated TS type stays `number`. No chunk breaks.
Tenant/security impact: none — no RLS change, no new PHI field, no new public surface.
IRD/regulatory impact (billing changes only): n/a
Alternatives considered:
  (a) keep integer and floor in the mapper — contradicts 02-TRD §4.1 "2 decimals" (floor is only used for the summary text, 02-TRD.md:160);
  (b) string "24.00" — no spec basis for decimal-as-string in DTOs, and it would also violate the current contract.
Tests that will prove it:
  C10 culture.reads.integration.test.ts M2: body conforms to CultureDetailDto AND observations[0].hours_since_planting === 24 (stored 24.00);
  culture.reads.test.ts unit row '24.17' maps to 24.17 and validates against ObservationDto.
