(3) LD-81 fixes kid = pat-YYYY-MM but not where the signer gets the YYYY-MM (key file name? separate env? signing month?). resolvePatientSession's wired signer fails closed (common.internal) until ruled.

(2) `core.memberships.patient_account_id uuid NULL` + partial UNIQUE (tenant_id, patient_account_id) WHERE NOT NULL, plus the A28.2 allowlist entries; C2 then implements the three repo methods in core-admin.repo.ts.

(4) lead names the patient refresh operation (operationId, path, response carrying `session_token`); C2 then implements it with the same rotate-before-mint + lost-race-as-reuse logic as refreshMobileSession.
