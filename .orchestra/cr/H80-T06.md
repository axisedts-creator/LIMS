Title: CR-C7-0xx: E22 `Driver` carries the driver's parser-options JSON Schema (`optionsSchema`)
From chunk: C7            To owner: C0-0B (contracts/openapi/instruments.yaml `Driver`) + C7 doc owner
Type: api
Blocking? no for H80-T06 tests (web reads an optional field and renders nothing when absent); yes for the real app to show the "options form from the schema" (H80-T06 done_when).
Problem: 04-UI-UX §3 step 3 says parser options are "rendered from the driver `optionsSchema`"; 02-TRD line 528 defines `optionsSchema` on the driver module; 08-ADDENDUM-TRUTH-H80E §8 lists the truth_h80e options. But the E22 `Driver` item (02-TRD line 738, contracts/openapi/instruments.yaml) has no such field, so `GET /v1/instruments/drivers` never returns the schema and the web form cannot build the fields.
Proposed change (exact): add optional `Driver.<name chosen by contract owner>`: `type: object` (a JSON Schema, read-only, from the driver module's `optionsSchema`) to `Driver` in contracts/openapi/instruments.yaml and 02-TRD §5 E22 Driver list. The web currently reads `options_schema` (the snake_case convention of the other Driver fields) from one accessor `driverOptionsSchema()` in apps/web/src/features/instruments/components/InstrumentForm.tsx; rename it there once the name is fixed. Also add the field to `apps/web/src/features/instruments/server/types.ts` `Driver` and update the rs-c7 byte-identical baseline for `features/instruments/server/**` (LD-140), which this lane may not change on its own.
Backward compatible? yes (new optional response field).
Tenant/security impact: none. Driver catalogue data, no PHI, no RLS change, no new surface. The web renders schema text as text only and skips `__proto__`/`constructor`/`prototype` keys.
IRD/regulatory impact: none.
Alternatives considered: hard-code the truth_h80e options in the web (rejected: LD-139 says no hard-coded guesses; the schema is owned by the driver). Keep the field in server/types.ts now (rejected by H80-T06 review: breaks rs-c7 baseline and invents a contract name).
Tests that will prove it: apps/web/src/features/instruments/__tests__/h80-t06.components.test.tsx (options form tests); an API contract test that E22 returns the schema for truth_h80e.
