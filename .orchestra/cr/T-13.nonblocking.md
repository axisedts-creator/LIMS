Title: CR-C1-T13: mark wave-1 agent, provider-callback and payment operations `x-edge-exposure: public` so gen-routes.sh can drop its SEED
From chunk: C1            To owner: C0-0B (contracts/openapi; C7, C6, C15 operation owners)
Type: api
Blocking? no for T-13 static tests (SEED is the interim basis). Yes for the 02-TRD s6.3 / CR-C1-004 rule "nothing is hand-added to `public-routes.yaml`".
Problem: 02-TRD s6.3 lists these routes as public edge routes, but no contract operation carries `x-edge-exposure: public`. Without the marker, `infra/ci/gen-routes.sh` cannot generate them, so the agent (AC-04.8), provider-callback and payment (AC-04.9, CR-C15-008) locations would be missing. T-13 adds them through a hand-kept SEED in `infra/ci/gen-routes.sh`.
Proposed change (exact): add `x-edge-exposure: public` to:
- contracts/openapi/instruments.yaml: `/v1/instruments/agent/enrolments`, `/v1/instruments/agent/config`, `/v1/instruments/agent/heartbeats`, `/v1/instruments/agent/message-batches`, `/v1/instruments/agent/host-queries`, `/v1/instruments/agent/attachments`, `/v1/instruments/agent/log-bundles`, `/v1/instruments/agent/releases/{release_id}/package` (C7 E01-E08).
- C6 provider-callbacks operations CB1 (POST) and CB2 (GET) under `/v1/reporting/provider-callbacks/`.
- C15 payment operations P30-P34 under `/v1/payments/result`, `/v1/payments/launch/`, `/v1/payments/callbacks/` (GET/HEAD only, CR-C15-008 item 2).
Backward compatible? yes (extension attribute only; no request/response change).
Tenant/security impact: no RLS / PHI change. Public surface is the same set 02-TRD s6.3 already declares; the marker makes it generated and drift-checked (CI job edge-routes-drift) instead of hand-kept.
Alternatives considered: keep SEED (violates "nothing hand-added"); drop the routes (breaks agent enrolment, provider callbacks and payment return in wave 1).
Tests that will prove it: after the change, delete SEED in `infra/ci/gen-routes.sh`; `bash infra/ci/gen-routes.sh | diff - infra/edge/public-routes.yaml` stays empty and `infra/tests/static/test_t13_edge.py` stays green.
