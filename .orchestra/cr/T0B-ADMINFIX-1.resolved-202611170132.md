Proposed change (exact), core/ports/registry.ts portsFor getter:

  + if (consumers[port]?.includes(module) || owners[port] === module) return impl; // a module may read the port it owns
  (owners = PORT_OWNERS already in scope at registry.ts:42; PORT_CONSUMERS / contracts unchanged.)
Backward compatible? yes — only widens the owner's view of its own port; no other module gains a port; production already returned impl (with a log line).
