# AG-T08 tests (transports: TCP client/listener + serial)
- Files: apps/bridge-agent/internal/transport/tcp/tcp_test.go (pkg `tcp_test`), .../transport/serial/serial_test.go (pkg `serial_test`). Run: `.orchestra\notes\AG-T08-verify.cmd` (= `go test -count=1 ./internal/transport/...` in apps/bridge-agent).
- Covers AC-07.1 at transport level (MLLP bytes incl. junk prefix arrive verbatim, 1-byte fragmentation, both modes, 2 MiB not truncated; extract/discard/count is internal/mllp, not here), TRD §5.8 validation, peer allowlist + flood (REQ-SEC-114), second conn replaces first, backoff 1s->max.
- API `tcp`: `ListenConfig{BindAddress string; Port int; AllowedPeers []string}`; `ValidateListenConfig`; `Listen(cfg)(*Listener,error)` (NO validation inside: tests bind 127.0.0.1:0; must still fail on ""/non-IP/wildcard bind); `(*Listener).Accept(ctx)(net.Conn,error)` (closes non-allowed peers at once, bumps `Rejected() uint64`, closes previous conn on new one; empty allowlist = reject all), `Addr()`, idempotent `Close()` that unblocks Accept. `ClientConfig{Host string; Port int; ConnectTimeout, ReconnectMaxBackoff time.Duration}`; `ValidateClientConfig`; `Dial(ctx,cfg)(net.Conn,error)`; `Backoff(attempt int,max time.Duration)` = 1s,2s,4s.. capped, overflow-safe; `Reconnect(ctx,cfg,sleep func(context.Context,time.Duration) error)(net.Conn,error)` (nil sleep = real ctx-aware).
- API `serial`: `Config{PortName string; BaudRate, DataBits int; Parity, StopBits string; DTR, RTS *bool}`; `ValidateConfig`; `Open(cfg)(io.ReadWriteCloser,error)` validates first; Close must unblock a pending Read.
- Serial pair tests skip as `[manual]` unless env `LIMS_SERIAL_PAIR=COMx,COMy` (com0com-class pair on the runner). Not run against hardware.
- NOT run to green: packages don't exist yet; go.mod also lacks go.bug.st/serial (impl must `go get go.bug.st/serial@v1.8.0` + tidy; tester may not edit go.mod).
