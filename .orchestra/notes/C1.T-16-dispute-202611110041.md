the regex is `(?m)^\s*(OnUnitActiveSec|...)...$|(?m)^\s*OnCalendar...`. A global flag `(?m)` after the `|` is a compile error on Python 3.11+
(`re.PatternError: global flags not at the start of the expression at position 76`; running Python 3.14). The test errors before it
looks at any timer content, whatever the writer ships.

`infra/ansible/roles/lims_runtime/files/lims-container-health.timer` present (`OnUnitActiveSec=30s`).

Fix (tester): put `(?m)` once at the very start, e.g. `r"(?m)(^\s*(OnUnitActiveSec|OnUnitInactiveSec)\s*=\s*30\s*(s|sec|seconds)?\s*$|^\s*OnCalendar\s*=.*\*:\*:(00?/30|0,30|00,30)\b)"`.
