1. infra/ansible/roles/clamav/templates/clamd.conf.j2:3 — clamd will not stay up in the official image. The ClamAV image entrypoint starts `clamd --foreground &` and then waits for a unix socket at `/run/clamav/clamd.sock` (or `/tmp/clamd.sock`). After `CLAMD_STARTUP_TIMEOUT` (1800 s) it exits, and that stops the container. This clamd.conf sets only `TCPSocket`, so no socket ever appears. The compose file already mounts the tmpfs `/run/clamav`, so the socket has somewhere to go. Fix: add `LocalSocket /run/clamav/clamd.sock` right after `TCPAddr 0.0.0.0`. clamd still listens on TCP 3310, which is the only listener the spec names. Then add an assertion to test_t22_clamav.py that the rendered clamd.conf contains `LocalSocket /run/clamav/clamd.sock`.
