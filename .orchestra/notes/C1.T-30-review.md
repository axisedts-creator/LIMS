   - `systemctl edit sshd` without a tty fails the same way.
   - If a permission does exist, the test actually starts the prod decrypt unit or reads /etc/shadow.
   This is the 07-SEC check "ops_oncall cannot run non-allowlisted sudo / decrypt prod secrets", and it must test the permission, not the command's outcome.
   Fix: as root, ask sudo's policy without running anything:
   `if sudo -l -U "$U" $c >/dev/null 2>&1; then tap fail ...; else tap ok ...; fi` (line 27), and
