# C1.T-31 dispute (writer)
Test: `test_t31_runbooks.RunbookLinkLint.test_every_alert_anchor_exists_with_the_entry_template` (only failing test; 35/36 pass).
Defect: the Severity check cannot pass for two alerts whose rule severity is not a literal page|warn|info:
- `Watchdog` (ops.rules.yml) has `severity: none`; the test regex `Severity:\s*(page|warn|info)` can never match `none`, so any correct runbook fails.
- `TargetDown` has `severity: '{{ if match "^(data|app|prod)-" $labels.host }}page{{ else }}warn{{ end }}'` (a template, set by T-19 for the lean profile, LD-45); the test compares `page` with that whole string, so `page` or `warn` both fail.
Both runbook entries exist with the full template (`ops.md#watchdog` says `Severity: none`; `host.md#targetdown` says `Severity: page` and explains page for prod hosts / warn otherwise).
Fix proposed (tester side, no rule edit): accept `none` in the regex, and for a templated severity accept any literal `page|warn|info` that appears inside the template string.
