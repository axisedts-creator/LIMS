# C1.T-34 dispute (writer)

(verified: `printf '%s' "$1" | od -c` shows `1 . 2 . 3`, 5 bytes), so the script receives the valid string `1.2.3` and rightly exits 0.
The script itself rejects a real newline (`[[ $version != *[[:space:]]* ]]`, anchored regex); on Linux the case passes. Request: drop that case on win32 or test it through a
here-file/`bash -c`. Not editing the test.
