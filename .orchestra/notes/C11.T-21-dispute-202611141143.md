## 1. `t21.signout.test.tsx`: `confirmSign()` never opens the dialog (21 tests)
`const confirmSign = async () => { const d = await dialog(); await userEvent.click(attest(d)); ... }` where `dialog = () => screen.findByRole('dialog')`.
The callers do `await open(); await confirmSign();` (also `open(...)` then `confirmSign()` in every "422 report_incomplete", "other sign-out errors", "security" and the first "submit (R3)" test) and never click `[Sign out]` first. Nothing opens a dialog by itself, so `findByRole('dialog')` times out.
The tests that do work use `dialog_open()` (click `signBtn()` then `dialog()`).
Fix (test side): `confirmSign` should start with `await userEvent.click(signBtn())`, or call `dialog_open()`.
Affected: submit(R3) #1; 5 x report_incomplete; order_item_inactive; 7 x it.each lab/anatomic/common; unknown code; auth.forbidden; JWT. (`after Cancel ... second attempt` is #2.)

## 3. Select accessible name: tests anchor on the label, react-aria puts the value first (10 tests)
Kit `Select` (react-aria) names the trigger `"{selected value or placeholder} {label}"`. Observed in the DOM: `"Grade 3 Grade (required)"`; empty: `"Select an item Grade (required)"`.
Tests use `getByRole('button', { name: /^grade/i })`, `/^grade.*grade 3/i`, `/^reason/i`, `/^kind/i`. `^label` can never match, and `^grade.*grade 3` cannot match `"Grade 3 Grade ..."`.
