The code sums both, so a test with a generic rule and a specific rule for one item gets its standard cost counted twice.    Fix: make `standardRules` also select `id, effective_from, effective_to, is_active`, with `effective_from`/`effective_to` as ISO text. In `addStandard`, build the needs with `matchRules` from `domain/rules.ts`, not the inline filter. Add a golden integration case: one generic `per_test` rule plus one `per_test` rule for instrument X1 on the same item, and expect only the X1 rule's cost.
