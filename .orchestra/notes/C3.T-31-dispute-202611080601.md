# C3.T-31 dispute — web-t31.server.test.ts cannot import any server function (test defect)
- Test: `apps/web/src/features/catalog/__tests__/web-t31.server.test.ts:34` — `const mod = (op) => import(\`../server/${op}.server\`)`. All 40 non-health tests fail with `Error: Unknown variable dynamic import: ../server/<op>.server`.
- Why: Vite (7.3.7, `dynamicImportToGlob`, config.js:28094) turns the template into the glob `../server/*.server`. `path.extname` of that glob is `.server` (so no "extension missing" error), but the glob matches only files literally named `<op>.server`. Files are `<op>.server.ts` (02-CONVENTIONS §2.4) and cannot be renamed; the glob can never match, whatever the writer does.
- Fix (tester): put the extension in the static part — `import(\`../server/${op}.server.ts\`)` — or build the loader with `import.meta.glob('../server/*.server.ts')`. Assertions themselves look right; nothing else disputed.
