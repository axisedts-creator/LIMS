# C9.T-14 dispute (1 test, test-side bug)
Test: chart.service.test.ts:61-64 "decimals / unit: no unit in the catalog -> unit_code omitted; no decimals -> 0".
Cause: chart.helpers.ts:131 `const { unitCode = 'mg_dl', decimals = 1 } = o;` — destructuring defaults replace an explicit `undefined`, so makeChartCatalog({ unitCode: undefined, decimals: undefined }) still seeds unit 'mg_dl' and decimals 1. The catalog never lacks them; the test cannot pass for any implementation (service returns unit_code 'mg_dl' = what the catalog holds).
Fix (tester): in makeChartCatalog use `'unitCode' in o ? o.unitCode : 'mg_dl'` and `'decimals' in o ? o.decimals : 1`.
Service behaviour pinned by that test is implemented: unit_code omitted when the analyte has no unitCode; decimals absent => 0.
