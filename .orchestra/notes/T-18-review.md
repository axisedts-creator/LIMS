1. infra/ansible/roles/monitoring/tasks/main.yml:153-155 — the ops nginx htpasswd is written `owner: root`, `mode: "0400"`. nginx reads `auth_basic_user_file` in the **worker** process (user `nginx`, uid 101 in the official image) on every request. The worker cannot read the file, so every request to ops nginx returns 500 and Grafana, Prometheus and Alertmanager are unreachable over wg0 (02-TRD §3.3, §11.5). Fix: for this item set `owner: root`, add `group: "101"` and `mode: "0440"` (or `owner: "101"`, `mode: "0400"`). Add uid 101 to `monitoring_uids` as `ops_nginx: 101` and use that key.
