# T0D-15 dispute (writer) — 3 test defects; implementation verified on corrected scratch copies (deleted)
1. test/widgets_cr16_test.dart lines 18 and 46: `$,` inside single-quoted group names is a Dart compile error ("A '$' has special meaning inside a string"), so the whole file fails to load. Fix: escape (`\$`) or use raw strings `r'...'`. With only that fix, 21/21 pass.

Fix: `'breadcrumbs': [ {...} ]`. With only that fix, 11/11 pass.
3. test/dependency_pins_test.dart lockfile regex uses `\n`; on Windows with core.autocrlf the checked-out pubspec.lock is CRLF and every package "is not in committed pubspec.lock". Writer normalised the working copy to LF (git stores LF), but a fresh checkout breaks again. Fix: `lock.replaceAll('\r\n', '\n')` (or .gitattributes `pubspec.lock eol=lf`, C0-0A).
