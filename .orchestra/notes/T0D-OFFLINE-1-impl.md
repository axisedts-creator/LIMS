[CONV] outbox: UUIDv7 with monotonic counter; append = crypto first, then one readwrite tx; a batch settles (remove, attention, conflicts, number mappings) in one tx. Reused from Flutter outbox: op_id idempotency, attempts, outcome code, separate conflict list.
[CONV] engine: one batch per syncOnce, shared flight, Web Locks ifAvailable leader, BroadcastChannel claim fallback (best effort); 401/403/5xx/timeout/malformed back off, nothing removed.
