# WEB-T03 dispute (writer)
Tests below cannot pass with ANY spec-conformant implementation (evidence from running web-t03.components.test.tsx against the writer impl). Everything else is implemented; remaining failures are only these.
1. **SCR-05 columns (l.114)**: `getByRole('columnheader', {name: /State/i})` matches both "State" and "Link state" (spec lists both columns) → "Found multiple elements". Fix: anchor, e.g. `/^State$/i`.
2. **"3 unmapped" (l.133)**: fixture rows 1, 4 and 5 all have `unmapped_code_count: 3` → `getByRole('link', {name: '3 unmapped'})` is always multiple. Fix: use `getAllByRole` or distinct counts.
3. **Alt+N on SCR-05 (l.167-180)**: `shortcuts.register` throws for `Alt+N` (`GLOBAL_KEYS` in core/shortcuts/registry.ts contains it; same conflict WEB-T02 hit → CR-C7-WEB-T02-d). Spec table 04-UI-UX §4 vs registry conflict; needs a CR, not a test of the impl.
4. **Select buttons `/^agent/i`, `/^driver/i` (l.214, 222, 310, 389)**: kit `Select` button accessible name is "<selected value or placeholder> <label>" (aria-labelledby = value id + label id; verified: "AG — x Agent", "Select an item Agent"). A name starting with the label is impossible. Fix: drop the `^` anchor (kit tests use `/Specimen type/`). Blocks every create-form test that calls `fill()`.
5. **`getByLabelText(/^host/i)` (l.293, 356)**: also matches the "Host query" switch (spec §SCR-06 requires both "Host" and "Host query"). Fix: `/^host$/i` or `/^host\b(?! query)/i`.
7. **AC-03.3 422 test (l.442-453)**: its `api.use(http.patch(...))` override returns the problem without calling `rec(request)`, so `calls` stays empty and `waitFor(() => expect(calls).toHaveLength(1))` can never pass. Fix: call `await rec(request)` in the override.
6. **301-char paste (l.787-798)**: kit TextArea passes `maxLength=300` to the textarea; user-event truncates the paste to 300 chars, which is a valid reason → request sent. Test expects none. Fix: type 300 + 1 chars is impossible with maxlength; assert `value.length <= 300` and that the body is ≤ 300 instead.
