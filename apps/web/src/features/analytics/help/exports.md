# My exports

## Purpose
Lists the files you asked for with Export on any report page, and lets you download them. Internal MIS: not a statutory register.

## Fields
- **Requested**: when you asked, in Nepal time (UTC+05:45).
- **Report and Period**: what was exported, with the period in A.D. and B.S.
- **Format**: Excel, CSV or PDF (PDF may not be available yet).
- **Status**: Queued and Building are in progress, Ready can be downloaded, Failed did not work, Expired is no longer available.
- **Rows and Size**: the size of the file.
- **Downloads**: used and allowed, for example "1 of 3".
- **Expires**: after this time the file is deleted.

The list refreshes every 3 seconds while a file is being built. If it takes longer than 2 minutes, use the refresh button.

## Rules
Exporting always needs MFA: verify with your authenticator app when asked (a verification code). Before exporting you confirm that you will keep the file inside the lab and delete it when no longer needed. The limit is 366 days per export.

If an export fails: "Too much data" means choose a shorter period or fewer centres; "You no longer have access to this data" means your access changed.

## Freshness
A file holds the figures as they were when it was built. Later changes are not included, so the numbers can be out of date compared to the screen. Build a new export for fresh numbers.
