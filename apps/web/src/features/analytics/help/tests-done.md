# Tests done

## Purpose
Shows the lab's output: how many results and tests were completed, by department, test or processing branch.

## Metrics
- **Results (analyte level) (M40 to M46)**: resulted, verified, approved, amended, auto-verified, critical and abnormal. Each is counted on its own event date. Abnormal is counted on the date the result first arrived.
- **Tests completed (M47)**: order tests that reached approved, counted on the approval date. This is the headline figure; the dashboard tile "Results approved" shows M42.

One test can have several analyte results, so the analyte-level counts are higher than Tests completed.

Filters: processing branch and department. Group by Department, Test, Processing branch, Day, A.D. month or B.S. month.

## Periods and business day
A business day runs 00:00–24:00 Nepal time (UTC+05:45). The period shows both A.D. and B.S. dates.

## Freshness
"Updated {time}" shows the last calculation. "Data may be out of date" means changes are still being processed.

## Centre scope
Figures follow the centre where the sample was collected. You only see centres you have access to. Users with access to all centres see all centres.
