# Phlebo applications

People who want to work as a phlebotomist apply from the phlebotomist app. Each application shows here.

## Review an application
1. Open **Home collection > Phlebo applications**. The **Waiting** list shows new applications.
2. Choose **Review** on a row.
3. Check the details: mobile, email, area and how the person wants to work (full time, or part time with shifts).
4. Open each document: licence or council registration, training certificates, citizenship or ID, photo. Each opens as a download.
5. Choose **Approve**, or write a note and choose **Reject**. A note is needed to reject.

## Good to know
- Only one open application is kept for a mobile number.
- Documents are at most 2 MB each and only people with this permission can open them.
- A decision cannot be changed here. If two people decide at once, the second is asked to refresh.
