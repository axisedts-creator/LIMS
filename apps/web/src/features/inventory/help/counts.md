# Stock count

Count what is on the shelf and post the differences. See stock-count.md for the full count guide.

- Choose "New count", pick the store (and optionally a category).
- Enter the Counted quantity per line. The system quantity is hidden (blind count) unless you hold stock adjust permission and switch it on.
- Review the variance, then "Post count" and choose whether uncounted lines stay unchanged or count as zero.

- A back-dated movement entered before a posted count changes the stock valuation of that past date. The count is not re-opened. Back-dating is allowed within the limit set in Settings.
- Topic guide: stock-count in the manual.
