# Inventory home

Shows what needs attention today: stock below reorder level, lots expiring soon, expired stock on hand and consumption waiting for a store.

- Read the four tiles: Below reorder, Expiring in N days, Expired on hand, Waiting consumption. Each tile opens the matching alerts or waiting list.
- If the warning banner says "Automatic consumption is off. Stock is not deducted for tests, QC or reruns until a manager turns it on in Settings.", ask a manager to open settings.
- Check the 10 newest open alerts and the set-up checklist (stores, items, packs, rules, analyser bindings, opening balances, consumption switched on).
- Use "New PO" or "Receive goods" in the header for the two most common jobs.

- The checklist disappears once every step is done.
- How consumption is counted: see the help page consumption_model.
