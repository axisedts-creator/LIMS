# Item detail

One item with tabs: Overview, Packs, Barcodes, Stock, Movements, Rules and Suppliers. Open it from the items list at /inventory/items.

- Edit the item on Overview and save the section.
- On Packs, choose "Add pack": code, label, unit, quantity in base unit and whether it is the purchase default.
- Pack size cannot change. Add a new pack instead.
- On Barcodes, scan or type a barcode and pick the pack it belongs to.

- Stock, Movements and Rules tabs show only this item.
