# Goods receipt

Record goods that arrive, with lot number and expiry for each line. Start from a PO ("Receive") or choose "New receipt".

- Pick the store and supplier; enter supplier invoice number, date and total if you have them.
- Per line enter pack, quantity, lot number (printed on the pack) and expiry. An expired lot cannot be received.
- If the invoice total differs from the calculated total, a warning shows the difference.
- Press "Post receipt" and confirm. Stock is added and the receipt can no longer be edited.

- Opening balances appear only for users with stock adjust permission.
