# Reports

Tabs: Daily consumption, Analyser-wise, Cost per test, Wastage, Expiry, Valuation and Reconciliation. Pick a date range (366 days at most) and press "Export CSV" if you may export.

- Choose a tab and filters (store or branch, analyser, test, item).
- Cost per test shows Direct, Loaded and Standard cost. Footnote: CPT excludes wastage, expiry and count differences. See the Wastage report.
- Reconciliation is shown only to users who see all centres.

- Money columns show only with cost permission. Guide: cost-per-test.md.
- How consumption is counted: see the help page consumption_model.
