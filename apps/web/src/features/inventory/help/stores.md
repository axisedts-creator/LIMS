# Stores and analyser links

Lists stores per branch and has two tabs on a store: Reorder settings and Analysers. Create or edit a store in the right drawer.

- Create a store: branch (create only), code (16 characters at most), name, kind. Tests and QC from analysers without their own store are deducted in the default consumption store.
- On Reorder settings, type the reorder level, reorder quantity and maximum level per item and choose a preferred supplier. Each row saves when you leave the field.
- On Analysers, link an analyser to a store. Waiting records for that analyser are then posted shortly.

- Only stores of your visible branches are listed.
