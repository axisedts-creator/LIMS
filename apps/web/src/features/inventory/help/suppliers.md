# Suppliers

Lists suppliers and the items each one supplies. Create or edit a supplier in the right drawer.

- Enter code, name and the PAN / VAT no. as on the supplier invoice. Contact name, phone, email, address and payment terms are optional.
- On the Items tab, add the item, pack, supplier code, last price and lead time.
- Save the section.

- Supplier prices appear only for users with cost permission (inventory.cost.read).
