# Approval

## Purpose

Approve verified results, singly or in bulk. The person who verified a result cannot approve it.

## Steps

1. Open the queue; it shows who verified each row and when.
2. Select rows with Space and extend with Shift+Down.
3. Press "Approve {n}". If multi-factor sign-in is required you are asked to confirm, then approval continues.
4. Read the summary dialog: "{ok} done, {failed} not done" with reasons.

## Shortcuts

- Space — select a row
- Shift+Down — extend selection downwards
- Alt+A — approve in the result grid

## Error messages

- "Nothing waiting for approval." — the queue is empty.
- "You verified this result. Another pathologist must approve it."
- "Record the critical-value notification before approving."
- "This item was changed by someone else. Reload to see the latest." — press Reload, then redo your change.
- "You don't have access to this screen." — your role does not include this screen. There is no Retry button; ask your administrator.
- "Something went wrong" — "Please try again. If it keeps happening, give this reference to support: {request_id}". Press Retry; if it repeats, give the reference to support.
- "This item doesn't exist or isn't visible to you." — the link is wrong or the item belongs to another organisation. The message is the same in both cases.
