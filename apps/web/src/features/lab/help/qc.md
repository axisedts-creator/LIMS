# QC results

## Purpose

Record quality-control results from instruments or by hand. Results are captured only. Pass and fail rules arrive with the QC module, so nothing is marked pass or fail.

## Steps

1. Open the list; columns show time, instrument, analyte, control, lot, level, value, unit and source (Instrument or Manual).
2. Press Add and fill centre, instrument, analyte, control, value and result time. Lot, level and unit are optional.
3. Save. The new row appears at the top.

## Shortcuts

- Tab and Shift+Tab move between fields
- Esc closes the Add dialog

## Error messages

- "No QC results captured." — nothing recorded yet.
- The page title reads "QC results (captured — rules arrive with the QC module)".
- "You don't have access to this screen." — your role does not include this screen. There is no Retry button; ask your administrator.
- "Something went wrong" — "Please try again. If it keeps happening, give this reference to support: {request_id}". Press Retry; if it repeats, give the reference to support.
- "This item doesn't exist or isn't visible to you." — the link is wrong or the item belongs to another organisation. The message is the same in both cases.
