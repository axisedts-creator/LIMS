# Receive specimens

## Purpose

Receive specimens at the lab by scanning, accept or reject them, and create aliquots. A session log shows the last 50 actions.

## Steps

1. Choose the Receiving location (required). Switch Auto-accept on only if your lab accepts every scan.
2. Scan the specimen barcode. The specimen card shows the patient, tests, collection details and any warnings.
3. Press Accept. To reject, press Reject, choose a reason, add a comment (up to 500 characters) and tick "Request recollection" if needed.
4. To split a specimen, accept it first, then press Aliquot: enter 1 to 10 aliquots, a tube type if different, and at least one test each.

## Shortcuts

- Enter — Accept
- R — Reject
- A — Aliquot (only after accept)
- O — Open specimen
- Scanning is turned off while a dialog is open.

## Error messages

- "Collection barcode was not verified on the phlebotomy app" — check the tube against the order.
- "Order cancelled — do not process" — set the specimen aside.
- "Rejected on {date}: {reason}" — already rejected.
- "Specimen rejected. New barcode {new_barcode} created for recollection." / "Specimen rejected."
- "Created {n} aliquots" — press "Print labels" to print them.
- "Close the dialog before scanning" — close the open dialog first.
- "You don't have access to this screen." — your role does not include this screen. There is no Retry button; ask your administrator.
- "Something went wrong" — "Please try again. If it keeps happening, give this reference to support: {request_id}". Press Retry; if it repeats, give the reference to support.
- "This item doesn't exist or isn't visible to you." — the link is wrong or the item belongs to another organisation. The message is the same in both cases.
