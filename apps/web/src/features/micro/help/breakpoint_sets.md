# Breakpoint tables

## Purpose

Keep the breakpoint tables used to suggest AST categories. A table belongs to one standard (CLSI, EUCAST or ECOFF) and one version. The list is at /micro/breakpoint-sets.

## Steps

1. Download the CSV template from the import dialog.
2. Fill one line per interpretive band. The header row must not change.
3. Choose Import and select the file. The import is checked in the background; open the set to see the status.
4. Fix any listed issues in the file and import again. Warnings do not block activation.
5. Preview, then activate a set. Activation needs a second person. The previous set for the same standard is closed automatically.

## Licence

The file must contain only breakpoint data your laboratory is licensed to use. You are responsible for holding the licence for the standard and version you import. The system does not supply breakpoint data.

## Error messages

- "A required column is missing from the header row." — the header does not match the template.
- Issues name the field and row, and never repeat long cell content.
