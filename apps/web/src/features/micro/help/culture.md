# Culture

## Purpose

Work one culture from set-up to report: plates, reads, isolates, identification, AST and reports. The page is at /micro/cultures/{culture_id}.

## Steps

1. Set up: add plates (medium, incubation start) on the Set-up tab.
2. Record reads and observations as the plates are read.
3. Add an isolate for each organism that grows, then identify it. Isolate numbers are per specimen and are never reused; withdraw an isolate instead of deleting it.
4. Assign an AST panel to the isolate. For each antibiotic enter the raw value (for example MIC or zone) and the category. Choose the breakpoint standard (CLSI, EUCAST or ECOFF) and its version first; every result stores both.
5. Send a preliminary report when you need to release early, and a final report when the culture is complete. Both go for verification.
6. If a sent final report needs a correction, use Reopen for amendment and choose a reason. The earlier versions stay readable; the new report is an amendment.

## Reading the category "I"

"I" does not mean the same thing under both standards. Under CLSI, I is Intermediate. Under EUCAST, I is "susceptible, increased exposure": the drug works if dosing or exposure is raised. CLSI also has SDD (susceptible, dose dependent). The page always shows the standard and version next to the category. Colistin and polymyxin B under CLSI accept only I and R.

## Error messages

- "The final report has been sent. Reopen the culture to make changes." — reopen for amendment first.
- "Choose a reason for the amendment." — the reopen dialog needs a reason.
