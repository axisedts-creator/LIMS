# QC run

## Purpose
One QC run with its control values, the rules that fired, and what people did about it.

## Actions
You need the review permission for these.
- **Evaluate now** (E): evaluates a run that is still collecting values. With fewer controls than planned it is marked Incomplete unless a rule is violated.
- **Record corrective action** (C): for a rejected run. Pick the action, describe what was done and when.
- **Close run**: for a rejected run once a corrective action is recorded and a later run was accepted. Patient results held by the failure stay on hold until released in Lab › Settings › QC holds.
- **Acknowledge** (A): for a run accepted with a warning. A comment is required.
