# QC runs

## Purpose
Lists QC runs: one run is one set of control values measured together on one instrument for one analyte.

## Fields
- **Observations**: values received out of the values a complete run needs, for example "2 / 2".
- **Outcome**: Accepted, Accepted (warning), Incomplete or Rejected. A run that is still waiting for values shows Collecting.
- **Rules**: the rules that failed, as text.
- **Needs action**: Corrective action needed (record what was done) or Rerun needed (run QC again).

## Rules
Newest runs come first; this order cannot be changed. Open a run to evaluate it, record a corrective action, close it or acknowledge a warning.
