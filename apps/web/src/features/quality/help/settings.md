# Quality settings

## Purpose
Limits that control TAT alerts, QC target set-up and auto-verification shadow runs, plus the coded lists used by QC screens.

## Settings
- **TAT alerts**: switch alerts on or off; warning at 50–99 % of target, escalate at 101–1000 %, close orphan clocks after 1–720 hours.
- **QC**: minimum points to establish a target (2–500; common practice is about 20, check your SOP) and the re-process window (1–30 days).
- **Auto-verification**: minimum simulation days (1–90) and minimum shadow decisions (10–100000) before a version can be activated.
- **Read-only**: Westgard mode and the auto-verification switch come from tenant settings (Admin › Tenant settings).

Each card has its own **Save**. It saves that card; the other cards keep their stored values. If someone else changed the settings meanwhile, reload the page and try again.

## Coded sets
Corrective actions and exclusion reasons. Edit a code's display text, order and active flag; the code itself cannot change. Editing needs the configuration permission.
