# QC set-up: Materials

## Purpose
Control materials are the products you run as QC. Each material has levels (for example Level 1 and Level 2) and each level has lots.

## Fields
- **Code**: capital letters, digits, "-" or "_" (2–32 characters). It cannot be changed later.
- **Levels**: one to six rows; each level code is used once per material.
- **Lot number**: printable characters, no space at the start or end.
- **Expires on**: a lot that has expired cannot be used for new QC.

## Rules
Deactivating a material keeps it readable. Lots that expire within 30 days are marked in the list.
