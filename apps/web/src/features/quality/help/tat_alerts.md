# TAT alerts

## Purpose
Open turnaround-time (TAT) alerts for the tests in your centres, highest level first. Each row names its segment: **Within lab** (received → first verified result) or **Total** (registration → report released). Hover or focus the segment for the full definition.

## Levels
- **Warning**: the clock passed the warning percentage of its target.
- **Breached**: the target time is over.
- **Escalated**: the clock passed the escalation percentage.

## Acknowledge
Select **Acknowledge** (or focus a row and press **A**), add an optional note (up to 500 characters) and confirm; Enter in the note confirms, Shift+Enter starts a new line. An acknowledgement is kept for the record. If the alert later reaches a higher level the row shows "New level since acknowledgement" and can be acknowledged again. You need the acknowledge permission.

## Notes
The list refreshes every 30 seconds while this tab is visible. You only see the centres you work in.
