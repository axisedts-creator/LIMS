# Delivery

## Purpose
One delivery attempt chain in detail. The page explains in plain words why a message was not sent or failed, and lists each attempt in time order.

## Fields
- **Channel**, **Purpose**, **Recipient**, **To**: the destination is masked. The message text, links, one-time codes and the full number are never shown.
- **Reason**: for example "Not sent: the patient has not agreed to this channel", "no phone number or email on file", "the provider is not responding; we will try again", or "Sending failed after several tries".
- **Attempts**: each attempt with its time and outcome.
- **Resend**: for a failed delivery, if you may resend. It starts a new attempt; it does not change the old ones.
- **Back to delivery log** returns to the list with your filters.

## Shortcuts
This screen has no page shortcuts. Use Tab and Enter; Esc closes a dialog.
