# Narrative report

## Purpose
Write the findings for an imaging or narrative test. Each section of the template has its own editor. Save your work as a draft as often as you like. When the report is complete, sign it. A signed report is locked: later changes need an amendment with a reason.

## Fields
- **Template**: changing it on a draft that already has text asks before the text is replaced.
- **Sections**: required sections are marked. Formatting is limited to bold, italic, underline, lists, tables, and two heading sizes. Pasted text is kept as plain text.
- **Images**: PNG or JPEG only, up to 12 images, each with a caption of up to 200 characters.
- **Save draft**: keeps your text without signing. The footer shows when it was saved.
- **Sign report**: asks you to confirm, then locks the report. You need the sign permission.
- **Start amendment**: available on a signed report; choose a reason (free text is required for Other) and edit a new version.

## Shortcuts
- `Ctrl+S`: save the draft.
- `Ctrl+Enter`: sign the report (opens a confirmation). Only with the sign permission.
- `Alt+I`: add an image.
