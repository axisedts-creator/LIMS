# Outsourced reports

## Purpose
Tests sent to an outside lab come back as a PDF. Upload the PDF here, check that it belongs to the right patient, and confirm it. Only a confirmed file goes into the report. Every uploaded file is checked for viruses and rebuilt in a safe form before it is shown.

## Fields
- **Reg no**, **Patient**, **Test**, **External lab**: which order and test the file is for.
- **File state**: Awaiting file, Checking, Preparing, Awaiting confirmation, Confirmed, Rejected, or Blocked.
- **Upload**: PDF only, up to 15 MB. The external lab name is required (up to 120 characters).
- **Confirm**: tick "I have checked that this report belongs to" the patient, then Confirm. A confirmed file cannot be confirmed again.
- A rejected file explains why: encrypted, damaged, too many pages, or took too long to check. A blocked file was stopped by the virus scanner.

## Shortcuts
This screen has no page shortcuts. Use Tab and Enter to move through rows and buttons; Esc closes a dialog.
