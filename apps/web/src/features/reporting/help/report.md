# Report

## Purpose
One report for one order. Check the items, the versions, and the deliveries, then release, print, or download it. If the report is held for dues, the banner shows the amount. A user who may record an override can do so from the banner; the release dialog opens again afterwards.

## Fields
- **Items**: each test or package and whether its lab result, narrative, or outsourced file is ready.
- **Versions**: newest first, with the kind (Final, Amended, Addendum), release time, basis, pages, and a Download link. Discarded versions are behind Show discarded.
- **Deliveries**: counts by status, and a link to the delivery log filtered to this report.
- **Release**: choose who gets the report. The patient is always included. Print only sends no messages.
- **Print**: choose with letterhead or plain paper and 1 to 5 copies. A version that is not released yet prints stamped NOT RELEASED and needs both the print and release permissions.
- **More actions**: Regenerate (reason required; free text is required for Other) and Revoke QR (cannot be undone).

## Shortcuts
- `Alt+R`: release the latest version.
- `Alt+P`: print (opens the paper dialog).
- `Alt+D`: download the PDF.
