# Report templates

## Purpose
Report templates control how printed and PDF reports look: page, letterhead, header fields, results layout, signatories, QR code, watermark, and disclaimers. This list shows the templates for your lab. Open one to edit its draft.

## Fields
- **Name**: opens the template editor.
- **Family**: Laboratory or Narrative.
- **Published version**: the version new reports use.
- **Draft**: the version you are editing, if any. A draft changes nothing until it is published.
- **Active**: whether the template can be used for new reports.

## Shortcuts
This screen has no page shortcuts. Use Tab and Enter to move through the list.
