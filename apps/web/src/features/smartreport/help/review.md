# Smart summary review

## Purpose

Read exactly what the patient will see, check it against the approved results, then approve or reject it. You are the named pathologist for this decision, and your approval is recorded with your name and the time. The responsibility for each sentence is yours (B14).

## What you see

- **What the patient will see** (left): score card, body-system tiles, findings outside range, trends, advice, follow-up suggestions and the disclaimer.
- **Results used** (right): the approved results, units, reference ranges and bands the summary was built from. Results that are not mapped to a body system are counted but not included.
- **Header**: status, registration no., centre, the library version ("Library v{n}") and the formula code hs-1.
- **History**: who approved, rejected or replaced the summary, and when.

## Actions

Actions need the permission to approve summaries.

- **Approve** (Ctrl+Enter): confirms that you read every sentence and that it is appropriate for this patient. After approval the PDF report includes the summary the next time it is generated. Use Regenerate on the report screen to add it now.
- **Reject** (Ctrl+Shift+R): pick a reason. A written reason is required for "other".
- **Approve & next** (Ctrl+Shift+Enter): approve and open the next summary in the queue.
- **Rebuild with active library**: shown only when a newer approved library exists.
- **Rephrase with AI**: only when the lab has switched on the optional Phase 3 feature. You still approve the final wording.

## About the score

The health score uses the published formula hs-1. It is a weighted summary of results in range. It is non-diagnostic: it is not a diagnosis and it does not replace a doctor's advice.

Approved, rejected and superseded summaries are read-only.
