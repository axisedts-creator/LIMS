# Identity and administration: user manual

How lab administrators manage users, roles, branches, collection centres, lab settings, sessions and audit records, and how every staff member signs in and manages their own account. All examples use synthetic data.

The admin screens use the standard look (LD-140): lists open a right drawer for editing, and each section or tab has its own Save button.
