# Patient engagement manual

Pages for staff who run bookings, the queue and patient app access, and one page for patients. Each staff page mirrors the in-app help of the same screen (the `helpKey` is named on the page).

## Staff pages

| Page | Screens |
|---|---|
| [Bookings and slots](bookings.md) | Bookings, booking detail, new booking, slot templates, bookable catalogue |
| [Queue](queue.md) | Queue console, queue setup, display screens |
| [Patient app access](app-access.md) | Issue and revoke app codes, with the identity check |
| [Reminders, memberships and enquiries](reminders-memberships-enquiries.md) | Follow-up reminders, membership cards, patient enquiries |
| [Engagement settings](settings.md) | Feature switches, consent text, legal links |

## For patients

- [How the app protects your reports](how-the-app-protects-your-reports.md) is the page the patient app opens from its About screen. It uses plain words and no staff terms.
