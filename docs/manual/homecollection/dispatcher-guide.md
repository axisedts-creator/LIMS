# Home collection: dispatcher guide

This guide is for the person who plans the day's home visits. It mirrors the in-app help for the dispatch board (`/homecollection/dispatch`) and the visit page (`/homecollection/visits/<id>`).

## The board

Pick the **Date** and the **Centre** at the top, then press **Refresh**. Visits nobody has taken are on the left under **Unassigned**. Each phlebotomist's route is a card on the right, in the order they will visit. Turn on **Needs attention** to see only visits with an open flag; every flag is written in words.

## Plan a visit

1. **Schedule**: open the **⋯** menu on an unassigned row, choose **Schedule**, then set the time window, the address and a note for the phlebotomist. Do not write test names, results or diagnoses in the note; it is shown on the phone.
2. **Assign**: choose **Assign** and pick a phlebotomist. The list shows how many visits each person already has that day. A full route cannot be chosen. For a booking, assigning also registers the order and issues the bill in front desk.
3. **Reorder**: use **Move up** and **Move down**, then **Save order**. The phone shows the new order after its next sync.
4. **Print labels**: opens the tube labels for the visit's order. You only see it if your role allows printing labels.

## Change or stop a visit

- **Unassign** takes the visit off a route. It needs a reason.
- **Cancel** closes the visit. It also needs a reason. Cancelling does not cancel the order or the bill in front desk; do that there if needed.

## The visit page

Open a visit to see its steps, its flags and what the phlebotomist recorded.

- **Show phone** reveals the patient's phone number for a short time. Each reveal is logged, so use it only when you need to call.
- **On hold**: a collection the phlebotomist held back (for example a doubtful tube) waits for a review. Open it, read the reason and press **Review**; then either release it or keep it held.
- **Missed**: a visit that passed its window without being collected is flagged as missed. Resolve the flag, then **Revisit** to create a new visit for the same order.
- **Revisit** also covers a patient who was not at home: it schedules another attempt and keeps the history.

## Keyboard

**Alt+D** goes to the date field and **Alt+R** refreshes. On an unassigned row **Alt+S** schedules and **Alt+A** assigns. **Ctrl+Enter** submits an open dialog and **Esc** closes it. Route order is changed with buttons only, so it works without a mouse.

## Good habits

Check the **Needs attention** view at the start and end of each shift. Assign early, because a phone only learns about a new visit at its next sync.
