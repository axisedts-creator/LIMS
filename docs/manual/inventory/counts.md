# Stock count

## Purpose

Count what is on the shelf and post the differences. See stock-count.md for the full count guide. Screen: /inventory/counts.

## Steps

1. Choose "New count", pick the store (and optionally a category).
2. Enter the Counted quantity per line. The system quantity is hidden (blind count) unless you hold stock adjust permission and switch it on.
3. Review the variance, then "Post count" and choose whether uncounted lines stay unchanged or count as zero.

## Tips

- A back-dated movement entered before a posted count changes the stock valuation of that past date. The count is not re-opened. Back-dating is allowed within the limit set in Settings.
- Topic guide: [stock-count.md](stock-count.md).
- Free text fields are staff text. Do not enter patient details. Use synthetic names in training.
