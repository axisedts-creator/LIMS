# Item detail

## Purpose

One item with tabs: Overview, Packs, Barcodes, Stock, Movements, Rules and Suppliers. Open it from the items list at /inventory/items. Screen: /inventory/items.

## Steps

1. Edit the item on Overview and save the section.
2. On Packs, choose "Add pack": code, label, unit, quantity in base unit and whether it is the purchase default.
3. Pack size cannot change. Add a new pack instead.
4. On Barcodes, scan or type a barcode and pick the pack it belongs to.

## Tips

- Stock, Movements and Rules tabs show only this item.
- Free text fields are staff text. Do not enter patient details. Use synthetic names in training.
