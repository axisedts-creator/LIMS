# Items list

## Purpose

Lists every reagent, kit, consumable, control and calibrator the lab stocks. Create or edit an item in the right drawer. Screen: /inventory/items.

## Steps

1. Filter by category, active or code/name prefix (60 characters at most).
2. Choose "New item". Enter a code (upper case, letters, digits, underscore, dot, hyphen; 32 at most), name, category, base unit and whether lots are tracked.
3. Save the section. Open an item to see packs, barcodes, stock, movements, rules and suppliers.

## Tips

- The base unit cannot change once the item has a pack, a rule or stock. Create a new item instead.
- Free text fields are staff text. Do not enter patient details. Use synthetic names in training.
