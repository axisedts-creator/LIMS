# Settings

## Purpose

Lab-wide inventory switches. Managers edit; other users see a read-only list. Screen: /inventory/settings.

## Steps

1. Automatic consumption: switch on and set "Start from". The start cannot be earlier than one hour ago, so nothing is deducted for the past. While it is off, stock is not deducted for tests, QC or reruns.
2. VAT included in cost: Turn off if your lab can claim purchase VAT back (ask your auditor). It changes future receipts only. See vat-in-cost.md.
3. Review PO approval, receipt without PO, over-receipt tolerance, expiry alert days, default consumption store, lock store during count, analyser-day rule activity, reconciliation alert percentage, back-dating limit and number patterns.

## Tips

- Free text fields are staff text. Do not enter patient details. Use synthetic names in training.
