# Stores and analyser links

## Purpose

Lists stores per branch and has two tabs on a store: Reorder settings and Analysers. Create or edit a store in the right drawer. Screen: /inventory/stores.

## Steps

1. Create a store: branch (create only), code (16 characters at most), name, kind. Tests and QC from analysers without their own store are deducted in the default consumption store.
2. On Reorder settings, type the reorder level, reorder quantity and maximum level per item and choose a preferred supplier. Each row saves when you leave the field.
3. On Analysers, link an analyser to a store. Waiting records for that analyser are then posted shortly.

## Tips

- Only stores of your visible branches are listed.
- Free text fields are staff text. Do not enter patient details. Use synthetic names in training.
