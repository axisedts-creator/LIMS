# Suppliers

## Purpose

Lists suppliers and the items each one supplies. Create or edit a supplier in the right drawer. Screen: /inventory/suppliers.

## Steps

1. Enter code, name and the PAN / VAT no. as on the supplier invoice. Contact name, phone, email, address and payment terms are optional.
2. On the Items tab, add the item, pack, supplier code, last price and lead time.
3. Save the section.

## Tips

- Supplier prices appear only for users with cost permission (inventory.cost.read).
- Free text fields are staff text. Do not enter patient details. Use synthetic names in training.
