# Waiting consumption

## Purpose

Lists deductions that could not be posted because no store is linked to the analyser and no default store is set. Screen: /inventory/unresolved.

## Steps

1. Choose "Post to store..." and select the store, or link the analyser on the Analysers tab.
2. Use "Dismiss" with a reason only if the record should not be deducted.

## Tips

- The Waiting consumption tile on the home page counts these records.
- Free text fields are staff text. Do not enter patient details. Use synthetic names in training.
