# Worklists — user manual

**Screen:** `/lab/worklists`

This page is part of the lab user manual. The same steps appear in the in-app help (press F1 or the ? icon).

## Purpose

See pending tests for a department, work through them in priority order and group a selection into a printable worksheet. Department pages are at /lab/worklists/{department_id}.

## Steps

1. Pick a department card; it shows open and urgent counts.
2. Filter by instrument, priority (All, Urgent, Routine), status or processing centre. Urgent items come first, then oldest received.
3. Press Enter on a row to open the order result grid filtered to the department.
4. Select rows with Space, press Alt+W, enter a worksheet title (required, up to 80 characters) to create a worksheet.

## Shortcuts

- Enter — open the order results
- Space — select a row
- Alt+W — create worksheet from selection (Ctrl+W is reserved by browsers)

## Error messages

- "No pending tests for this department." — nothing to do; this is not an error.
- The instrument filter is hidden when you may not list instruments.
- "You don't have access to this screen." — your role does not include this screen. There is no Retry button; ask your administrator.
- "Something went wrong" — "Please try again. If it keeps happening, give this reference to support: {request_id}". Press Retry; if it repeats, give the reference to support.
- "This item doesn't exist or isn't visible to you." — the link is wrong or the item belongs to another organisation. The message is the same in both cases.

## Tips

Keep the barcode scanner pointed at the label and wait for the confirmation before the next scan. All names in training material must be synthetic; never type real patient data into a practice system.
