# Culture workflow

This page follows one culture from the bench to the final report. All screens are under Microbiology in the menu.

## 1. Find the work

Open /micro/worklist (shortcut g u). The tabs show where each item stands: Awaiting setup, Incubating, Growth / work-up, Amending and Recently submitted. Scan a specimen barcode to start a culture for it, or press Enter on a row to open it at /micro/cultures/{culture_id}.

## 2. Set up and plates

On the Set-up tab choose the culture type and add each plate with its medium and incubation start. A plate can be discarded with a reason; it is kept in the history. The culture then moves to Incubating, and the worklist orders it by the next read due time.

## 3. Reads and isolates

Record each read with the growth code and any observation. When an organism grows, add an isolate. Isolate numbers count up per specimen and are never reused. Identify the isolate from the organism dictionary. A wrongly added isolate is withdrawn with a reason, not deleted.

## 4. AST

Assign a panel to the isolate, then enter the raw value and category for each antibiotic. See [AST entry and categories](ast-entry-and-categories.md).

## 5. Preliminary and final reports

Send a preliminary report when results must be released before the culture is complete. Send the final report when every reportable isolate is identified and every reportable AST row has a raw value, a category, a breakpoint standard and a version. Each submission is a numbered version (P1, P2, F1) and goes for verification. After the final report is sent the culture is locked; to correct it see [Amendments](amendments.md).

## 6. Instrument results

Results sent by instruments appear under Micro instrument data. See [Instrument data matching](instrument-data-matching.md).
