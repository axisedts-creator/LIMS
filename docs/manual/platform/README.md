# Platform console: user manual

How LIMS provider staff provision and look after tenant labs, track IRD annexes, open support sessions, handle dead letters and manage platform staff. The platform console has its own header colour and the label "PLATFORM CONSOLE — the LIMS provider staff only". Lab staff never see it. All examples use synthetic data.
