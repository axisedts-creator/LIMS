# Platform home

## Purpose

The platform home gives LIMS provider staff a quick view of what needs attention across all tenant labs. Address: `/platform`. Permission: `platform.tenant.read`.

## Sections (tiles)

- **Tenants by status**: how many tenant labs are in each status, for example active or suspended.
- **Open dead letters**: background tasks that failed and wait for a decision.
- **Active support sessions**: support sessions running now in any tenant.
- **Incomplete IRD annexes**: tenants whose IRD annex records are not all complete.

Select a tile to open the matching list.

## Common tasks

- Start the day by checking open dead letters and replay or discard them; see [Dead letters](dead-letters.md).
- Check that no support session is running longer than needed; see [Support sessions](support-sessions.md).
- Follow up tenants with incomplete IRD annexes in the [IRD annex tracker](ird.md).
- Provision a new lab from [Tenants](tenants.md).
