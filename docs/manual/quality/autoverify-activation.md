# Four-eyes activation — user manual

**Screen:** `/quality/autoverify/{version_id}`

This page is part of the quality user manual. The same steps appear in the in-app help (press F1 or the ? icon).

## Purpose

Switch a simulated version on for real results. Activation needs a second person, so no one can activate their own rules (four-eyes).

## Steps

1. The author asks a colleague with the manage permission to open the simulated version.
2. The colleague reviews the report and presses Activate. A step-up sign-in may be asked; confirm it in the dialog.
3. The version becomes active and replaces the previous one.
4. To stop, press Retire. Results then fall back to manual verification.

## Shortcuts

- Tab and Shift+Tab move between fields
- Esc closes the dialog

## Error messages

- "You don't have access to this screen." — your role does not include this screen. There is no Retry button; ask your administrator.
- "Something went wrong" — "Please try again. If it keeps happening, give this reference to support: {request_id}". Press Retry; if it repeats, give the reference to support.

## Tips

- The author cannot activate the version they wrote. The button explains why.
