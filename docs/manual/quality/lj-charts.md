# Levey-Jennings charts — user manual

**Screen:** `/quality/lj`

This page is part of the quality user manual. The same steps appear in the in-app help (press F1 or the ? icon).

## Purpose

Follow a control level over time against its mean and SD lines (LJ chart). Each point is a QC value; its marker shape and a text label show whether it was accepted, a warning or rejected.

## Steps

1. Pick instrument, analyte and date range.
2. Read the summary sentence above the chart: points, rejected count, current target mean and SD.
3. Hover or focus a point to see its value, run and rule.
4. Open the data table below the chart for the same points as text.

## Shortcuts

- Arrow keys move between points
- Tab leaves the chart

## Error messages

- "You don't have access to this screen." — your role does not include this screen. There is no Retry button; ask your administrator.
- "Something went wrong" — "Please try again. If it keeps happening, give this reference to support: {request_id}". Press Retry; if it repeats, give the reference to support.

## Tips

- Colour is never the only signal: shapes and labels carry the status too.
