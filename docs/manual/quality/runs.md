# QC runs and corrective actions — user manual

**Screen:** `/quality/runs`

This page is part of the quality user manual. The same steps appear in the in-app help (press F1 or the ? icon).

## Purpose

Review QC runs and record a corrective action for every rejected run. A rejected run blocks the affected analyte in the lab until it is dealt with.

## Steps

1. Open QC runs and filter to Needs action.
2. Open a rejected run to see its points, the rules it broke and its history.
3. Press Record corrective action, choose the cause, describe what was done and Save.
4. Repeat the control. When an accepted run follows, close the rejected run.

## Shortcuts

- Tab and Shift+Tab move between fields
- Esc closes the corrective action drawer

## Error messages

- "You don't have access to this screen." — your role does not include this screen. There is no Retry button; ask your administrator.
- "Something went wrong" — "Please try again. If it keeps happening, give this reference to support: {request_id}". Press Retry; if it repeats, give the reference to support.
- "This item doesn't exist or isn't visible to you." — the link is wrong or the item belongs to another organisation.

## Tips

- A rejected run left without action for 4 hours raises an alert to operations.
