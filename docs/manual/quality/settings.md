# Quality settings — user manual

**Screen:** `/quality/settings`

This page is part of the quality user manual. The same steps appear in the in-app help (press F1 or the ? icon).

## Purpose

Tenant-level switches and limits for quality: the auto-verify feature switch, the minimum simulation days and decisions, and QC defaults.

## Steps

1. Open Quality settings.
2. Change a value; each section has its own Save.
3. Turning the auto-verify switch off makes every decision deny at once; turning it on needs an active version.

## Shortcuts

- Tab and Shift+Tab move between fields
- Esc closes a confirmation dialog

## Error messages

- "You don't have access to this screen." — your role does not include this screen. There is no Retry button; ask your administrator.
- "Something went wrong" — "Please try again. If it keeps happening, give this reference to support: {request_id}". Press Retry; if it repeats, give the reference to support.

## Tips

- Changes are audited with your name and time.
