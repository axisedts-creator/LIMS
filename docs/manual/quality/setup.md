# QC set-up — user manual

**Screen:** `/quality/setup/materials`

This page is part of the quality user manual. The same steps appear in the in-app help (press F1 or the ? icon).

## Purpose

Prepare QC in order: materials, maps, plans and targets. Writing needs the QC manage permission; everyone with QC access can read.

## Steps

1. Materials: add each control material with its lot and levels.
2. Maps: map a material and level to an instrument and analyte, so incoming results find their plan.
3. Plans: create the plan for the pair with its rule mode, validity window and run window. Activate it.
4. Targets: record the mean and SD for each level, from the lot sheet or from your own data.
5. Check Unassigned QC; rows there are results that no map accepted.

## Shortcuts

- Tab and Shift+Tab move between fields
- Esc closes the right drawer without saving

## Error messages

- "You don't have access to this screen." — your role does not include this screen. There is no Retry button; ask your administrator.
- "Something went wrong" — "Please try again. If it keeps happening, give this reference to support: {request_id}". Press Retry; if it repeats, give the reference to support.
- "This item doesn't exist or isn't visible to you." — the link is wrong or the item belongs to another organisation.

## Tips

- Each section of a drawer has its own Save.
