## Operators

[runbooks.md](runbooks.md) lists what to do for a stuck renderer, a spike in rejected files, a provider outage, a rejected WhatsApp template, callback token rotation, a mis-sent link, and a missing PDF.

Each staff screen has a short Help panel with the same Purpose, Fields, and Shortcuts sections. This manual adds the steps and the reasons behind them.
