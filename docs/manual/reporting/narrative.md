# Narrative report

Address: `/reporting/narratives/{narrative_id}`. Permission to open: `reporting.narrative.write`.

## Purpose

Write the findings for an imaging or narrative test. Each section of the template has its own editor. Save a draft as often as you like. When the report is complete, sign it. A signed report is locked: later changes need an amendment with a reason.

## Fields

- **Template**: changing it on a draft that already has text asks before the text is replaced.
- **Sections**: required sections are marked. Formatting is limited to bold, italic, underline, lists, tables, and two heading sizes. Pasted text is kept as plain text.
- **Images**: PNG or JPEG only, up to 12 images, each with a caption of up to 200 characters. Each image is checked before it can be used.
- **Save draft**: keeps your text without signing. The footer shows when it was saved.
- **Sign report**: asks you to confirm, then locks the report. You need the sign permission.
- **Start amendment**: available on a signed report.

## Steps: write and sign

1. Pick the template if it is not already chosen.
2. Fill every required section.
3. Add images with Add image or `Alt+I`, then write a caption for each.
4. Press `Ctrl+S` to save the draft.
5. Press Sign report or `Ctrl+Enter`, read the confirmation, and confirm.

## Steps: amend a signed report

1. Press Start amendment.
2. Choose a reason. Free text is required for Other.
3. Edit the new version, then sign it. The earlier version stays in the report history.

## Shortcuts

- `Ctrl+S`: save the draft.
- `Ctrl+Enter`: sign the report (opens a confirmation). Only with the sign permission.
- `Alt+I`: add an image.
