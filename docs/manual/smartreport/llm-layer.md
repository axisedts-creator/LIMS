# LLM layer (Phase 3)

This page applies only to labs that switch on the optional Phase 3 rephrasing layer. It is off by default. When it is off, none of the AI controls appear.

## What it does

When enabled, a reviewer can choose Rephrase with AI on a summary. The layer offers alternative wording for sentences that already come from the approved library. It does not add new findings, numbers or advice, and its output is checked before it is shown. If a check fails, the original approved text is kept and the item is marked Kept original.

## The pathologist still approves

The named pathologist compares the approved template text with the rephrased text side by side and decides. The Approve dialog has a switch, Use AI-rephrased wording, which is off by default. The history records when rephrasing was requested and by whom. Responsibility stays as described in [approval responsibilities](approval-responsibilities.md).

## Turning it on

The lab's settings control this feature. If you cannot see Rephrase with AI, it is not enabled for your lab, or you lack the permission to approve summaries.
