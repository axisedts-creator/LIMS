Status: DRAFT for build, 2026-11-05. Abbreviations as in `01-PRD.md`.

## 0. How to use this plan

- Four agents run in parallel, one per workstream (0A, 0B, 0C, 0D). Each edits only its sub-paths (`02-TRD.md` §1.1). Branch prefix: `c00-0a/…`, `c00-0b/…`, `c00-0c/…`, `c00-0d/…` (CV §12).
- One task = one PR where possible. "Depends on" lists hard prerequisites only. Everything else can run concurrently.
- Spikes (§1) come first. A task marked **gated by SP-n** may start its non-gated parts, but must not merge the gated part before the SP-n decision record is merged.
- Every task's "done-when" includes: CI green, AC tests listed pass, docs updated (DoD §1.9).
