## 6. Risks and mitigations

| Risk | Impact | Mitigation |
|---|---|---|
| Chromium repeated header/footer behaviour differs from expectation | layout AC fail | T05 spike first; three candidate techniques; acceptance tests, not technique, are the gate |
| Renderer memory creep / crashes at peak | delayed reports | pool recycle, memory cap, retries, stuck-render sweep, alerts; scale replicas (02-TRD §11) |
| Malicious outsourced PDF | RCE / data leak | sandbox without network/secrets, qpdf only, never Chromium; scanner; corpus tests |
| WhatsApp template approval delayed or business unverified (B9) | no WhatsApp | SMS first in channel order; email; print; T27 gated |
| Provider API details unknown (UNVERIFIED) | adapter rework | transport interface + recording adapter; docs-first tasks T27/T28 |
| Storage claims behaviour unverified (04 D3) | Storage policy unusable | all access via API/worker server credentials; no client Storage |
| Debounce/job-key race misses an update | stale report | `needs_assembly` flag + 5-min sweep; fingerprint idempotency |
| OTP brute force / SMS cost abuse via link | cost, access | 04 A9 limits, no OTP on page load, per-destination rate limit, alerts |
| Patient demographics corrected after release | wrong printed name | Regenerate → amended version; QR of old shows superseded |
| PDF size larger than the 150 KB assumption | storage growth | measure metric from day one; plain variants not stored |
